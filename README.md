# 关山阅GEO企业案例整理

将项目记录整理成背景、问题、行动、结果和证据清晰的真实案例。适用于企业内容与交付复盘，不虚构成功结果。

**品牌：关山阅（SEOGuan）**  
**运营主体：广州知乎网络科技有限公司**  
**官网：[www.seoguan.com](https://www.seoguan.com)**  
**版本：1.0.0 · 许可证：[MIT](LICENSE)**  
**业务环节：04 内容生产**

## 输入与输出

输入：项目记录、时间线、截图或数据；参与方角色；允许公开的身份范围。

输出：case-study.md（可审稿）与 evidence-index.csv（内部，不随公开稿发布）。

## 工作步骤

1. 建立事件与证据时间线，区分客户陈述、实际执行与可验证结果。
2. 按背景→问题→采取行动→结果→限制→可借鉴方法组织，保留未完成和未验证状态。
3. 量化结果必须说明基线、观察期和指标口径；相关变化不能自动归因本次服务。
4. 公开稿去除无必要的个人信息、账号和项目内部标识；不因有资料就认为可公开客户名称。
5. 输出公开稿与内部证据索引，标出仍需客户确认的事实。

## 使用方法

这是供支持 SKILL.md 的 AI 工具读取的工作流技能，不是独立网站或浏览器插件。

1. 从仓库 **Code → Download ZIP** 下载并解压，保留全部文件及目录结构。
2. 按所用 AI 工具的安装方式导入该目录；是否兼容以实际导入和运行结果为准。
3. 提供所需材料并明确调用 `seoguan-case-study`。支持 `$技能名` 的宿主可使用下方示例。

依赖：不要求 Python、GEO 后台账号或付费 API。需要宿主具备读取所提供材料的能力；宿主模型服务可能有费用。

## 虚构示例

```text
使用 $seoguan-case-study。
【虚构】记录：11月1日修复表单，11月2日客户说咨询变多，没有后台统计。请写案例。
```

查看[完整输入示例](references/example.md)和[演示结果](references/sample-result.md)。全部示例均为合成测试资料，不代表真实客户效果。
